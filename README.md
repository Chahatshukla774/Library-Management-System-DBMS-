# Library Management System

## Description
This is a Library Management System developed using MySQL and MySQL Workbench.

## Features
- Add Books
- Add Students
- Issue Books
- Return Books
- Manage Staff
- Maintain Issue and Return Records

## Technologies Used
- MySQL
- MySQL Workbench

## Database Tables
- BOOK
- STUDENT
- STAFF
- ISSUE_RECORD
- RETURN_RECORD
